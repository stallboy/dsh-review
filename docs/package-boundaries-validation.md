## 改动结果

根包只协调 npm workspaces、构建、测试和打包。插件源码、资源与 DSH 元数据位于 `packages/dsh-plugin`，中央接入适配位于其 `src/managed`。中央服务与中央 Web 继续位于 `apps/server`、`apps/web`。Web 使用的公开数据类型来自 `packages/protocol`，不再跨目录读取插件源码。

插件标识仍为 `dsh-code-review`，公开入口仍为 `dist/index.js` 和 `dist/client.js`。中央服务的默认静态资源目录改为自身的 `dist/public`。本次未提取独立审核核心包，未改变 HTTP 路径、审核业务、持久化结构或恢复语义。

## 独立交付验证

`npm run pack:plugin` 生成 `dist/dsh-code-review-0.3.0.tgz`；`npm run pack:central` 生成 `dist/dsh-review-server-0.1.0.tgz`。

两个安装包分别在系统临时目录使用全新空缓存离线安装，不位于源码仓库内，运行子进程清空 `NODE_PATH`，不能回退借用开发工作区依赖。

- 插件：实际导入公开入口、读取 classic Client、locale、图标、Cordis 配置及两个提示词；不携带中央服务、中央 Web 或 Fastify。
- 中央服务：实际创建 Fastify 应用，核验 `/health`、首页、首页引用的 JavaScript、SPA 路由及旧静态文件的 404；执行安装后 CLI 创建临时测试账号。
- 打包：在 `.tmp` 中根据 npm 实际运行依赖树物化包内容，再执行 npm pack，处理提升依赖与嵌套版本；临时目录自动清理。
