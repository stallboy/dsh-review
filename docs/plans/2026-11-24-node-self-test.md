# 节点审查流程自检实施计划

> **任务来源**: 用户确认中央服通过 /test 触发新节点的快速流程自检。
> **任务内容**: 在原有沙箱和权限下验证主代理、Codex、Claude Code 以及模拟记录发布和格式校验。
> **参考文档**:
> - `SPEC.md` — 审查编排、中央任务协议和滚动升级。
> - `docs/plans/2026-11-23-unified-audit-flow.md` — 统一阶段工具与各启动入口。
> **生成日期**: 2026-11-24

1. 在中央服接入已登录的 POST /test，将请求加入现有托管任务队列。验证幂等键、能力协商和旧节点行为。
2. 插件沿用桌面会话或后台 Runner 的真实主代理入口。通过现有阶段工具分别调用 Codex 和 Claude Code，由 Host 核对随机样本结果。
3. 复用发布和格式校验代码，在临时目录写入并读回模拟记录。验证失败步骤、取消、收尾和目录隔离。
4. 跑类型检查、构建和全量测试，逐条检查方案与实现是否一致。
