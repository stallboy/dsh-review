## 独立审查与逐条复核

执行设计阶段复核及完整分支对抗性审查，每条结论均再次核对源码和最小复现。最终独立复核结论为 **无未决 P0/P1/P2**。

已修复并补回归的成立问题：

- 停止期间在途轮询仍可能启动新任务；停止标记现在阻止后续执行。
- 单纯查询 pending 存在新指令竞态；改为原子暂停受理，配置握手完成后显式激活。
- 暂停被误当作实例租约失效；实例互斥现独立于受理状态。
- 自动续注册可能重新暂停或解除暂停；同实例保留中央状态，首次配置完成后清除本地配置标志。
- 切换中央时迟到登录可能写入新会话映射；所有相关异步边界校验连接代数。
- 本机退出或会话过期无法重新进入；仅安全重建用户会话，不重放业务写请求。
- 插件旧项目配置覆盖中央页面改名/停用；恢复只读取中央状态，显式用户操作才改启停。
- 加锁前写配置及加锁前启动快照覆盖并发停用；所有写入和恢复先取得所有权并重读。
- 中央模式中原本地入口可能绕过托管写入；UI 与 Host 同时保留写隔离。

新增测试中同实例 register 曾假定可解除暂停，现改为显式 activate，并增加暂停期间拒绝新指令的断言；属于跟随契约收紧。既有测试断言未放宽。
