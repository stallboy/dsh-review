## 修复内容

连接成功后以摘要和下一步操作替代启动表单，编辑连接独立展开；未变化的就绪配置不能重复应用。启动期间以同步请求锁去重，管理写入先取消并隔离旧轮询，写后重新读取状态才恢复可提交能力。读取失败时保持禁用，后续轮询恢复；服务可访问但节点离线单独提示。停止可使用已保存配置启动，错误和草稿保护保留。

旧隐藏规则依赖本机 DSH 不存在的 `data-conversation-content`。改为只在含评审标记的 `data-conversation-scroll` 隐藏直属 `data-composer-seat`，整体消除输入和任务区占位，不操作任务本身。只有无中央配置且非旧托管模式才显示原本地评审；停止与故障不回退。

中央差异使用文件级原生 details/summary，默认展开，支持单独折叠和批量操作。父候选页保留同范围刷新与审核标签切换的状态；候选、版本、范围变化实际清空旧记录。评论的文件、行号、LEFT/RIGHT 和增量比较限制保持不变。

新增用例先复现成功后未切换、重复应用、节点离线提示和导航问题；文件折叠用例在原实现没有 details 时失败，再实现。原布局字符串断言按实际宿主结构收紧，另外使用真实浏览器验证布局。
