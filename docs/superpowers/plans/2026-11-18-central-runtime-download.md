# 本机中央运行包按需下载实施计划

> **任务来源**: 用户确认轻量插件通过现有启动入口按需获取本机中央运行包，并在启动时检查新版。
> **任务内容**: 在同一 Git 仓库实现下载确认、校验缓存、后台版本提示及开发预览。
> **参考文档**:
> - `SPEC.md` — 插件中央连接与本机托管契约
> - `docs/central-deployment.md` — 中央与插件打包、安装和预览方式
> **生成日期**: 2026-11-18

1. 更新中央启动契约并补充界面和安装包测试，验证取消、确认及离线恢复。
2. 内置具体运行包描述，沿用现有应用和启动入口，验证下载失败发生在连接配置变更之前。
3. 复用本机市场预览和中央打包，验证从索引安装轻量包后实际下载、校验、启动及检查版本。
4. 在隔离 worktree 完成独立审查、类型检查、构建和全量测试。
