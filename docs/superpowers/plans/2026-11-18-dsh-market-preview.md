# DSH 市场开发预览实施计划

> **任务来源**: 用户确认通过 DSH 市场自动安装本机中央整合插件，当前阶段先在本地准备和验收，暂不发布到市场。
> **任务内容**: 将现有整合包准备为可由 npm 仓库分发的产物，并提供离线可复现的 DSH 市场安装入口。
> **参考文档**:
> - `SPEC.md` — 本机中央连接、启停及轻量包兼容契约。
> - `docs/central-deployment.md` — 现有整合包交付和中央首次配置流程。
> - `https://deepseek-harness.github.io/deepseek-harness/en/guide/plugin-market` — DSH 自定义市场索引格式和 npm 安装方式。
> **生成日期**: 2026-11-18

1. 先在 `tests/plugin-central-package.test.mjs` 验证整合包可以作为 npm 发布产物，源码、普通包及其安装路径仍保持现有行为。补上断言并确认缺少改动时会失败，再在 `scripts/pack.mjs` 中只移除暂存整合包的 `private` 字段。
2. 用 `npm run preview:market` 构建并提供同一份整合包。预览通过随机回环端口提供 DSH 格式 1 的索引、npm 元数据及 tarball；索引中的包名、版本和 registry 必须与实际安装目标一致。集成测试以索引为起点，在隔离目录按包名和版本安装，检查中央健康接口、页面和子进程退出。
3. 补充开发验收文档，记录市场入口、首次启动和验证范围。核对普通包、独立中央和本机托管的已有契约，运行类型检查、构建及全量测试。真实 DSH 市场安装或升级需在隔离的桌面环境单独验收。

预览仅在本机响应读取，保留包自身的 DSH 标识和版本。发布、市场收录、现用 DSH profile 和数据目录均在本次开发预览的操作范围之外。
